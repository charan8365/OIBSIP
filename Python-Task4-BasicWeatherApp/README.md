# Basic Weather App — OASIS INFOBYTE Task 4

A Python GUI weather application created for the OASIS INFOBYTE Python Programming Internship.

## Features
- Search weather by city name
- Current temperature and weather condition
- Feels-like temperature
- Humidity and wind speed
- Input validation
- City-not-found handling
- Network/API error handling
- Tkinter GUI
- Uses Open-Meteo APIs; no API key is required

## Technologies
- Python
- Tkinter
- Requests
- Open-Meteo Geocoding API
- Open-Meteo Weather API

## How to Run
```bash
pip install -r requirements.txt
python app.py
```
