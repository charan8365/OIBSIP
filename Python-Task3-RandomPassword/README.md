# Random Password Generator — OASIS INFOBYTE Task 3

A Python GUI application that generates secure random passwords using the `secrets` module.

## Features
- Adjustable password length from 4 to 64 characters
- Uppercase, lowercase, numbers and symbols options
- Guarantees at least one character from every selected category
- Secure random generation with Python's `secrets` module
- Password strength indicator
- Copy password to clipboard
- Clear generated password
- Input validation and helpful error messages
- Tkinter GUI

## Requirements
- Python 3.10 or later
- Tkinter (normally included with standard Python installations)

No external Python packages are required.

## How to Run
```bash
python app.py
```
